# Financial Performance Analysis | Power BI

## Project Overview
This project analyzes sample financial data
using Microsoft Power BI.

The objective is to understand sales performance,
profitability, and business trends.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Dashboard Features
- Total Profit
- Total Sales
- Gross Sales
- Total Discounts
- Units Sold
- Profit Margin
- Profit by Business Segment
- Sales Distribution by Country
- Yearly Profit Trends

## Key Insights
1. Government is the most profitable segment.
2. Enterprise is operating at a loss.
3. Paseo generates the highest product profit.
4. Profit increased between 2013 and 2014.

## Dataset
Microsoft Power BI Financial Sample Dataset.
